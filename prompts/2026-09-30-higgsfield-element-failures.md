# 2026-09-30 Higgsfield 엘리먼트 생성 실패 기록

## 요청

몽실이 4방향 엘리먼트로 기본 자세 변형과 소품(꽃다발 들고 뛰기) 이미지 생성

## 사용한 것

- 2D 턴어라운드 엘리먼트 여러 개를 한 프롬프트에 동시 투입
- GPT Image 2, Nano Banana

## 실패 내용

- 몸은 측면인데 얼굴만 정면으로 고정됨
- 표정 변화 없음, 몸 디테일이 살지 않음
- 그림체가 원본과 다름 (페인터리 질감, 장면형 배경)
- 결국 "전부 이상하고 어색하다"는 판정

## 원인

1. 같은 캐릭터 엘리먼트를 여러 개 넣어 모델이 여러 캐릭터로 해석
2. MCP로 만든 엘리먼트는 첫 이미지만 주입되는데 여러 장을 한 엘리먼트에 넣음
3. 배경과 스타일 지시가 캐릭터 그림체를 덮어씀
4. 소품까지 한 번에 요청해 자세 확인 단계를 건너뜀
5. Nano Banana 결과는 원본과 차이가 큼

## 수정 방법

- 엘리먼트 하나에 이미지 한 장으로 재등록
- 생성 시 몽실이 엘리먼트는 1개만 사용
- 흰 배경 & 소품 없이 자세부터 확인
- 몽실이 이미지 생성은 GPT만 사용

## 다음 작업에 재사용할 규칙

- 엘리먼트 1개 원칙
- 자세 → 소품 → 장면 순서
- 사용자가 요청하기 전에는 생성하지 않고 프롬프트만 준비
